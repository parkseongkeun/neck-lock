# Neck Lock PRD v1 (가칭)

- 작성일: 2026-10-12
- 상태: 스펙 확정 (구현 전)
- 배포 범위: 본인 맥 전용 (App Store 배포 안 함)

## 1. 목적

업무 시간 동안 매시 정각에 맥북 입력을 잠그고, 카메라 앞에서 목 스트레칭(고개 360° 돌리기)을 해야만 다시 쓸 수 있게 해서 **거북목을 방지**한다.

보안 목적이 아니다. 습관 강제 도구다.

## 2. 핵심 원칙

1. **화면은 덮지 않는다.** 화면은 그대로 보이고, 키보드·마우스 입력만 막는다.
2. 잠금과 동시에 **카메라 창**이 뜬다. 사용자는 내 얼굴과 원형 가이드를 보면서 동작한다 (토스 얼굴인증 느낌).
3. **누구 얼굴이든 상관없다.** 본인 확인은 하지 않고 동작만 판정한다.

## 3. 기능 명세

| 항목 | 스펙 |
|---|---|
| 트리거 | 업무 시간 중 매시 정각 (시계 기준) |
| 업무 시간 | 평일(월–금) 09:00–17:00 |
| 제외 시간 | 점심 12:00–13:00 |
| 잠금 시각 | 10:00, 11:00, 12:00\*, 14:00, 15:00, 16:00, 17:00 |
| 잠금 방식 | 키보드·마우스 입력 차단, 화면은 그대로 노출 |
| 카메라 창 | 화면 중앙 플로팅, 원형 얼굴 가이드 + 진행률 링 |
| 해제 조건 | 고개 360° 돌리기 **2바퀴** |
| 1바퀴 판정 | 왼쪽 → 아래 → 오른쪽 → 위 4구간을 순서대로 통과 (시계·반시계 방향 무관) |
| 예외 | "오늘 하루 끄기" 버튼 → 당일 남은 잠금 모두 건너뜀, 다음 날 자동 복구 |
| 상주 | 메뉴바 아이콘, 로그인 시 자동 실행 |
| 설정 | 업무 시간·요일·점심 시간, 회전 바퀴 수 |
| 카메라 실패 | v1 범위 밖 |

\* 정각 트리거 규칙의 경계값 처리는 §6 미결 사항 참고.

## 4. 사용자 흐름

```
[대기: 메뉴바 상주]
   │ 업무 시간 중 정각 도달
   ▼
[잠금] 입력 차단 + 카메라 창 표시
   │ 얼굴이 가이드 원 안에 들어옴
   ▼
[인식됨] "고개를 천천히 크게 돌려주세요" + 바퀴 카운터 0/2
   │ 4구간 순서대로 통과 → 1/2
   │ 다시 4구간 통과 → 2/2
   ▼
[완료] 체크 애니메이션 (≈1초)
   ▼
[해제] 입력 복구, 카메라 OFF → 다음 정각까지 대기
```

얼굴이 프레임 밖으로 나가면 진행 중인 바퀴는 유지하고, 다시 들어오면 이어서 판정한다.

## 5. 화면 상태

| 상태 | 카메라 창 표시 |
|---|---|
| 얼굴 찾는 중 | 회색 가이드 원, "얼굴을 원 안에 맞춰주세요" |
| 인식됨 | 가이드 원 활성 색상, 회전 안내 문구 |
| 회전 중 | 진행률 링이 4구간 단위로 채워짐, 바퀴 카운터 |
| 완료 | 체크 표시 후 창 닫힘 |

카메라 창 하단에 작은 텍스트 버튼으로 "오늘 하루 끄기"를 둔다.

## 6. 미결 사항 / 가정

- **"오늘 하루 끄기" 해석**: 대화 중 "오늘 미리 기준"을 "오늘 하루 미루기"로 해석했다. 짧은 스누즈(예: 10분 뒤 재잠금)가 의도였다면 수정 필요.
- **12:00 잠금 여부**: 12–13시를 빼는 기준이 "12시 정각부터 제외"인지 "12시 잠금은 하고 그 이후 제외"인지 확인 필요. 기본안은 **12:00 잠금 안 함** (점심 직전 나가는 시점이므로).
- **17:00 잠금 여부**: 업무 종료 시각 정각에도 잠글지 확인 필요. 기본안은 **17:00 잠금 안 함** → 최종 잠금 시각: 10, 11, 14, 15, 16시 (하루 5회).
- **맥이 잠자기 중일 때 정각이 지나간 경우**: 깨어난 뒤 소급 잠금하지 않고 다음 정각을 기다린다.

## 7. 기술 방향

본인 맥 전용이라 App Store 샌드박스 제약을 받지 않는다.

| 영역 | 선택 |
|---|---|
| 앱 형태 | Swift / SwiftUI 메뉴바 앱 (`LSUIElement`) |
| 입력 차단 | `CGEventTap`으로 키보드·마우스 이벤트 소비 → **손쉬운 사용 권한** 필요 |
| 카메라 | AVFoundation (`AVCaptureSession`) |
| 고개 각도 | Vision `VNDetectFaceRectanglesRequest` — yaw(좌우), pitch(상하) |
| 스케줄 | 정각 기준 타이머 + 잠자기/깨어남 알림(`NSWorkspace`) 처리 |
| 자동 실행 | `SMAppService.mainApp` (로그인 항목) |
| 설정 저장 | `UserDefaults` |

### 360° 판정 로직 (초안)

- yaw·pitch로 머리 방향을 4구간(좌/하/우/상)으로 분류. 각 구간은 임계각 이상일 때만 진입으로 본다 (기본 20°, 튜닝 필요).
- 마지막으로 진입한 구간에서 인접 구간으로 이동한 경우만 진행으로 인정. 4구간을 한 방향으로 모두 거치면 1바퀴.
- 고개를 뒤로 크게 젖히면 얼굴 검출이 끊길 수 있으므로 "위" 구간 임계각은 낮게 잡는다.

## 8. 안전장치 (개발용)

입력을 막는 앱이라 버그가 나면 맥을 쓸 수 없게 될 수 있다.

- **비상 해제 단축키**: 개발 빌드에서 특정 키 조합으로 즉시 해제.
- **최대 잠금 시간**: 일정 시간(예: 5분)이 지나면 자동 해제 (개발 빌드).
- 정식 사용 시 위 장치의 유지 여부는 별도 결정.
