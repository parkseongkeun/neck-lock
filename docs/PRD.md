# Neck Lock PRD v1 (가칭)

- 작성일: 2026-10-12
- 상태: 스펙 확정 (구현 전)
- 배포 범위: 본인 맥 전용 (App Store 배포 안 함)

## 1. 목적

업무 시간 동안 매시 정각에 맥북 입력을 잠그고, 카메라 앞에서 목 스트레칭(고개 360° 돌리기)을 해야만 다시 쓸 수 있게 해서 **거북목을 방지**한다.

보안 목적이 아니다. 습관 강제 도구다.

## 2. 핵심 원칙

1. **화면은 불투명하게 덮지 않는다.** 화면 내용은 비쳐 보이고, 키보드·마우스 입력만 막는다. (예외: 잠금 중 반투명하게 어둡게 하며, 방치 경고는 화면 *가장자리*에 붉은 빛을 띄운다. 둘 다 입력은 건드리지 않는다. §3 참고)
2. 잠금과 동시에 **카메라 창**이 뜬다. 사용자는 내 얼굴과 원형 가이드를 보면서 동작한다 (토스 얼굴인증 느낌).
3. **누구 얼굴이든 상관없다.** 본인 확인은 하지 않고 동작만 판정한다.

## 3. 기능 명세

| 항목 | 스펙 |
|---|---|
| 트리거 | 업무 시간 중 매시 정각 (시계 기준) |
| 업무 시간 | 평일(월–금) 09:00–17:00 |
| 제외 시간 | 점심 12:00–13:00 |
| 잠금 시각 | 10:00, 11:00, 12:00\*, 14:00, 15:00, 16:00, 17:00 |
| 잠금 방식 | 키보드·마우스 입력 차단, 화면은 그대로 노출 |
| 카메라 창 | 화면 중앙 플로팅, 원형 얼굴 가이드 + 진행률 링. 링 위의 점이 고개 방향을 따라가고, 점 뒤로 현재 바퀴 진행 선이 그려진다 (끝낸 바퀴는 옅게 유지) |
| 화면 잠금 중 정각 | 맥 화면(⌃⌘Q)이 잠겨 있는 동안 정각이 지나가면, **풀린 직후 같은 시간대(예: 11:00~11:59) 안일 때만** 잠금을 보충해서 건다. 시간대가 지났으면 그 회차는 포기 |
| 잠금 중 화면 | 모든 모니터를 **반투명(약 55%)하게 어둡게** 덮는다. 내용은 비쳐 보이고 카메라 창·붉은 테두리는 그 위에 보인다. 어두운 창도 클릭·키 입력을 가로채지 않는다(입력 차단은 CGEventTap이 담당). 설정에서 끌 수 있음(기본 켬) |
| 카메라 선택 | 메뉴바 "카메라"와 설정에서 내장·외장·아이폰(연속성 카메라) 중 고른다. 잠금 중에는 카메라 창의 "카메라 전환" 버튼으로 바꾼다 (잠금 중엔 메뉴바를 못 쓰므로). 고른 카메라가 없으면 시스템 기본으로 대체 |
| 방치 경고 | 잠긴 뒤 20초 동안 회전 누적이 늘지 않으면 화면 테두리가 붉게 맥동(주기 1.6초). 클릭·입력은 통과시키고, 다시 움직이거나 잠금이 끝나면 즉시 꺼짐. 시스템 "동작 줄이기" 설정 시 맥동 없이 고정. 설정에서 끌 수 있음(기본 켬). 메뉴바 "붉은 테두리 미리보기"로 확인 가능 |
| 해제 조건 | 고개 360° 돌리기 **2바퀴** (설정에서 1~5바퀴) |
| 1바퀴 판정 | 머리 방향이 원점 둘레를 도는 누적 각도 360° (시계·반시계 방향 무관, §7 참고) |
| 예외 | "오늘 하루 끄기" 버튼 → 당일 남은 잠금 모두 건너뜀, 다음 날 자동 복구 |
| 상주 | 메뉴바 아이콘, 로그인 시 자동 실행 |
| 설정 | 업무 시간·요일·점심 시간, 회전 바퀴 수 |
| 카메라 실패 | v1 범위 밖. 단, 카메라·권한 문제로 잠글 수 없으면 **잠그지 않고** 메뉴바에 경고만 표시 (fail-open) |

\* 정각 트리거 규칙의 경계값 처리는 §6 미결 사항 참고.

## 4. 사용자 흐름

```
[대기: 메뉴바 상주]
   │ 업무 시간 중 정각 도달
   ▼
[잠금] 입력 차단 + 카메라 창 표시
   │ 얼굴이 가이드 원 안에 들어옴
   ▼
[인식됨] "고개를 천천히 크게 돌려주세요" + 바퀴 카운터 0/2
   │ 4구간 순서대로 통과 → 1/2
   │ 다시 4구간 통과 → 2/2
   ▼
[완료] 체크 애니메이션 (≈1초)
   ▼
[해제] 입력 복구, 카메라 OFF → 다음 정각까지 대기
```

얼굴이 프레임 밖으로 나가면 진행 중인 바퀴는 유지하고, 다시 들어오면 이어서 판정한다.

## 5. 화면 상태

| 상태 | 카메라 창 표시 |
|---|---|
| 얼굴 찾는 중 | 회색 가이드 원, "얼굴을 원 안에 맞춰주세요" |
| 인식됨 | 가이드 원 활성 색상, 회전 안내 문구 |
| 회전 중 | 진행률 링이 4구간 단위로 채워짐, 바퀴 카운터 |
| 완료 | 체크 표시 후 창 닫힘 |

카메라 창 하단에 작은 텍스트 버튼으로 "오늘 하루 끄기"를 둔다.

## 6. 미결 사항 / 가정

- **"오늘 하루 끄기" 해석**: 대화 중 "오늘 미리 기준"을 "오늘 하루 미루기"로 해석했다. 짧은 스누즈(예: 10분 뒤 재잠금)가 의도였다면 수정 필요.
- **12:00 잠금 여부**: 12–13시를 빼는 기준이 "12시 정각부터 제외"인지 "12시 잠금은 하고 그 이후 제외"인지 확인 필요. 기본안은 **12:00 잠금 안 함** (점심 직전 나가는 시점이므로).
- **17:00 잠금 여부**: 업무 종료 시각 정각에도 잠글지 확인 필요. 기본안은 **17:00 잠금 안 함** → 최종 잠금 시각: 10, 11, 14, 15, 16시 (하루 5회).
- **맥이 잠자기 중일 때 정각이 지나간 경우**: 깨어난 뒤 소급 잠금하지 않고 다음 정각을 기다린다.

## 7. 기술 방향

본인 맥 전용이라 App Store 샌드박스 제약을 받지 않는다.

| 영역 | 선택 |
|---|---|
| 앱 형태 | Swift / SwiftUI 메뉴바 앱 (`LSUIElement`) |
| 입력 차단 | `CGEventTap`으로 키보드·마우스 이벤트 소비 → **손쉬운 사용 권한** 필요 |
| 카메라 | AVFoundation (`AVCaptureSession`) |
| 고개 각도 | Vision `VNDetectFaceRectanglesRequest` — yaw(좌우), pitch(상하) |
| 스케줄 | 정각 기준 타이머 + 잠자기/깨어남 알림(`NSWorkspace`) 처리 |
| 자동 실행 | `SMAppService.mainApp` (로그인 항목) |
| 설정 저장 | `UserDefaults` |

### 360° 판정 로직 (구현됨)

- 머리 방향을 2D 벡터 (yaw ÷ 20°, pitch ÷ 12°)로 보고, 이 벡터가 원점 둘레를 돈 **누적 각도**를 센다. 누적이 360° × 바퀴 수에 닿으면 완료.
- 반지름 1.0(좌우 약 20°, 상하 약 12°) 이상으로 **크게** 돌렸을 때만 누적한다. 0.8 아래로 내려오면 누적을 멈춘다 (경계에서 깜빡이지 않도록 히스테리시스).
- 누적에는 부호가 있다. 좌우로 흔들기만 하면 서로 상쇄돼서 진행되지 않는다. 시계·반시계는 무관.
- 얼굴이 프레임에서 사라지면 진행은 유지하고, 다시 잡히면 이어서 센다.
- Vision `VNDetectFaceRectanglesRequestRevision3`의 yaw·pitch(라디안, 연속값)를 쓴다. 부호 규약과 무관하게 동작한다.
- 임계값은 실제로 돌려보며 튜닝한다 (§10).

## 8. 안전장치

입력을 막는 앱이라 버그가 나면 맥을 쓸 수 없게 될 수 있다.

- **비상 해제**: ⌃⌥⌘⇧ + Esc.
- **최대 잠금 시간**: 기본 10분이 지나면 자동 해제 (설정 0~60분, 0 = 제한 없음).
- **시스템 보호**: 앱의 메인 스레드가 멈추면 macOS가 이벤트 탭을 꺼서 입력이 풀린다.
- **fail-open**: 손쉬운 사용 권한이나 카메라가 없으면 잠그지 않는다.
- **마우스**: 잠금 창 영역 안에서만 통과시킨다 ("오늘 하루 끄기" 버튼용).
- **잠금 안 하는 경우**: macOS 화면 잠금 중, 잠금 시각을 2분 넘겨서 알아챈 경우(잠자기 후 깨어남 등).
- **테스트**: 메뉴바 > "지금 테스트 잠금"으로 정각을 기다리지 않고 확인한다.

## 9. 범위 밖 (v1)

- 카메라 실패·어두운 환경 대응 (현재는 잠그지 않고 경고만)
- 회의·화면 공유 자동 감지
- 본인 얼굴 판별
- 통계·기록
- App Store 배포

## 10. 실기기 검증이 필요한 항목

개발 환경(Linux)에서는 macOS 앱을 빌드·실행할 수 없어서 아래는 아직 확인 전이다.

- 회전 판정 임계값(20°/12°, 반지름 1.0/0.8)이 실제 목 돌리기에 맞는지 → 설정의 "각도 표시"로 측정
- Vision pitch 값의 정확도, 고개를 뒤로 젖힐 때 얼굴 검출이 끊기는지
- 이벤트 탭 동작 (⌘Tab, 미션컨트롤, 전체화면 앱 위에서의 잠금 창 표시)
- 다중 모니터에서 잠금 창 위치와 마우스 허용 영역
- 외장 웹캠 사용 시 동작
